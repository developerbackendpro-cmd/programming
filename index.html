Dasturlash tili nima ?

Dasturlash tili — bu inson va kompyuter o‘rtasida muloqot qilish uchun ishlatiladigan maxsus til. Dasturchi shu til yordamida kompyuterga nima qilish kerakligini buyruqlar orqali tushuntiradi.

Masalan, dastur:

  • ma'lumotlarni hisoblaydi;
  • veb-sayt yaratadi;
  • mobil yoki desktop dastur yaratadi;
  • ma'lumotlar bazasi bilan ishlaydi;
  • robot va qurilmalarni boshqaradi;
  • sun'iy intellekt tizimlarini yaratadi.

Muhim fikr !

Dasturchi loyiha talabiga qarab til tanlaydi. Bir loyihada tez ishlab chiqish muhim bo‘lsa Python qulay bo‘lishi mumkin, yuqori unumdorlik va tizim ustidan nazorat kerak bo‘lsa C++ yoki Rust ma'qul bo‘lishi mumkin. Shuning uchun dasturlash tilini tanlashda loyiha turi, tezlik, xavfsizlik, platforma, jamoa tajribasi va ekotizim hisobga olinadi.

HTML - CSS - JAVASCRIPT

Bitta sahifaning uch qatlami: HTML — skelet, CSS — design, JavaScript — harakat

HTML:

HTML (HyperText Markup Language) — veb-sahifalarning tuzilishini yaratish uchun ishlatiladigan belgilash tili.

HTML tarixi 1989-yilda boshlangan. Uni britaniyalik olim Tim Berners-Lee CERN ilmiy markazida ishlab chiqqan. Uning asosiy maqsadi olimlar o‘rtasida hujjatlar va ma’lumotlarni internet orqali oson almashish imkonini yaratish edi.


Asosiy bosqichlar:

  • 1989 — Tim Berners-Lee World Wide Web g‘oyasini taklif qildi.
  • 1991 — birinchi HTML hujjati va dastlabki web-sayt yaratildi.
  • 1995 — HTML 2.0 standarti paydo bo‘ldi.
  • 1997 — HTML 3.2 chiqarildi.
  • 1999 — HTML 4.01 taqdim etildi va uzoq vaqt davomida keng ishlatildi.
  • 2014 — HTML5 rasmiy standart sifatida e'lon qilindi.
  • Hozirgi davr — HTML doimiy ravishda rivojlanib, zamonaviy web-ilovalarning asosiy texnologiyalaridan biri bo‘lib qolmoqda.

Qiziqarli fakt:

HTML dastlab bugungi kabi murakkab web-saytlar yaratish uchun emas, ilmiy hujjatlarni bog‘lash va ularga havolalar berish uchun yaratilgan. Tim Berners-Lee → HTML → Web → Zamonaviy Internet HTML — 1989-yilda boshlangan va bugungi web texnologiyalarining poydevoriga aylangan.

CSS:

CSS (Cascading Style Sheets) — web-sahifalarning ko‘rinishi va dizaynini boshqarish uchun yaratilgan texnologiya.


Asosiy bosqichlar:

  • 1994 — CSS g‘oyasi Håkon Wium Lie tomonidan taklif qilindi. Maqsad HTML tarkibi va sahifa dizaynini bir-biridan ajratish edi.
  • 1996 — CSS1 rasmiy tavsiya sifatida e'lon qilindi.
  • 1998 — CSS2 chiqarildi. U web-sahifalarni yanada murakkab boshqarish imkoniyatlarini qo‘shdi.
  • 2011 — CSS2.1 keng qo‘llaniladigan standartga aylandi.
  • 2010-yillar — CSS3 rivojlanishi bilan animatsiyalar, transition, gradient, flexbox va boshqa zamonaviy imkoniyatlar paydo bo‘ldi.
  • Hozirgi davr — CSS alohida bitta “CSS3” versiyasi sifatida emas, balki modullar bo‘yicha doimiy rivojlanadigan standart sifatida davom etmoqda.

JavaScript:

JavaScript yaratuvchisi — Brendan Eich.
U JavaScript'ni 1995-yilda Netscape kompaniyasida ishlab chiqqan. Dastlab til juda qisqa vaqt ichida yaratilgan va web-sahifalarga interaktivlik qo‘shish maqsadida ishlab chiqilgan.


Asosiy bosqichlar:

  • 1995 — JavaScript Brendan Eich tomonidan Netscape kompaniyasida yaratilgan.
  • 1995 — dastlab til LiveScript deb atalgan, keyinchalik JavaScript nomini oldi.
  • 1997 — JavaScript standartlashtirilib, ECMAScript standarti paydo bo‘ldi.
  • 2009 — Node.js paydo bo‘ldi va JavaScript'ni server tomonida ishlatish imkoniyati kengaydi.
  • 2015 — ECMAScript 2015 (ES6) chiqarildi. let, const, class, arrow function, Promise kabi ko‘plab zamonaviy imkoniyatlar qo‘shildi.
  • Bugungi kunda — JavaScript web dasturlashning eng muhim tillaridan biri bo‘lib, React, Vue, Angular, Node.js kabi ekotizimlarning asosini tashkil qiladi.

Server — bu nima va qanday ishlaydi ?

Server — boshqa qurilmalarga yoki dasturlarga ma’lumot va xizmat taqdim etadigan kompyuter yoki dasturiy tizim.


Oddiy qilib aytganda:

Server — so‘rovni qabul qiladi, uni qayta ishlaydi va natijani qaytaradi.


Server nimalar uchun ishlatiladi:

  • 🌐 Web-saytlarni ishlatish
  • 🔐 Foydalanuvchilarni autentifikatsiya qilish
  • 🗄️ Ma’lumotlar bazasi bilan ishlash
  • 📡 API orqali ma’lumot almashish
  • 📁 Fayllarni saqlash
  • 💳 To‘lovlarni qayta ishlash
  • 💬 Chat va real-time xizmatlar
  • ☁️ Cloud servislarni ta’minlash

Domen nima va qanday ishlaydi?

Kompyuterlar bir-birini raqam (IP) bilan topadi, odam esa nomni eslaydi. Domen — shu ikkisini bog'lovchi telefon kitobi. Yetti qadamli yo'lni kuzating.

Protokol

Protokol — tarmoqdagi qurilmalar o‘rtasida ma’lumot almashishni tartibga soluvchi aloqa qoidalari to‘plami. U ma’lumot qanday yuborilishi, qabul qilinishi, tekshirilishi va qayta ishlanishini belgilaydi.


Tarmoq qatlamlari

Tarmoq orqali ma’lumot uzatilishi bir nechta qatlamlar orqali amalga oshiriladi. Har bir qatlam o‘ziga tegishli vazifani bajaradi. Yuqori qatlamlarda foydalanuvchi va dastur bilan bog‘liq jarayonlar, quyi qatlamlarda esa ma’lumotni tarmoq orqali yetkazish jarayonlari amalga oshiriladi.


TCP — ma’lumotlarni ishonchli yetkazishga mo‘ljallangan transport protokoli. U ma’lumotlarning yetib borishini, tartibini va yo‘qolgan qismlarini nazorat qiladi.


UDP — tezkor ma’lumot uzatishga mo‘ljallangan transport protokoli. U yetkazib berishni tekshirish va qayta yuborish kabi qo‘shimcha jarayonlarni minimal darajada bajaradi. Shu sababli TCP'ga nisbatan yengilroq va tezkorroq ishlaydi.


HTTP — web brauzer va server o‘rtasida ma’lumot almashishni ta’minlaydigan protokol.


HTTPS — HTTP protokolining xavfsiz shakli bo‘lib, ma’lumotlarni shifrlangan holda uzatadi. Bu foydalanuvchi va server o‘rtasidagi ma’lumotlarning himoyalanishini ta’minlaydi.

Request va Response aslida nima?

Bu — xat yozish va javob olish. Chizmada so'rov va javobning tuzilishi, metodlar va status kodlar.

Cache nima uchun kerak?

Cache — tez-tez kerak bo'ladigan narsani qo'l ostida saqlash. Ikki yo'l yonma-yon: cachesiz 800 ms, cache bilan 15 ms.

Database turlari va farqlari

Ma'lumotni saqlashning bir necha shakli bor. Har bir kartochkada ma'lumot qanday ko'rinishda yotishi chizib berilgan.

CRUD amallari va filterlar

Har qanday ilova aslida 4 ta ishni qiladi: Create, Read, Update, Delete. Pastda esa filter va qidiruv chizmasi.

Backend API: web, desktop va mobil uchun yagona markaz

Bitta backend — uchta mijoz. So'rov API'ga boradi, API bazadan oladi va hammasiga bir xil ma'lumot qaytaradi.

Authentication va Authorization farqi

Authentication — "sen kimsan?" (pasport tekshiruvi). Authorization — "senga ruxsatmi?" (qaysi xonaga kira olasan). Ikkalasi yonma-yon chizmada.

JWT token qanday ishlaydi?

JWT — imzolangan bilet. Uch qismi, imzo qanday tekshirilishi va nega uni qalbakilashtirib bo'lmasligi.

Backup — bu nima va nega hayotiy?

Backup — ma'lumotning nusxasi. Vaqt o'qi, 3-2-1 qoidasi va "qancha ma'lumot yo'qoladi" degan savol.

Rate limit qanday ishlaydi?

Serverda ham "navbat" bor. Token savati qanday ishlashi va 429 javobi qachon qaytishi.

Docker nima va qanday ishlaydi?

"Mening kompyuterimda ishlayapti-ku!" muammosi: konteynersiz va konteyner bilan tarqatish yonma-yon.
